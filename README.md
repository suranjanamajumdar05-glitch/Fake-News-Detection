# Project Overview
This project detects whether a news article is Fake or Real using Machine Learning Techniques.
The system preprocesses news text, converts it into numerical features using TF-IDF Vectorization, and classifies the news using Logistic Regression.

# Objectives
1. Detect fake news articles automatically
2. Use Machine Learning algorithms for classification
3. Evaluate model performance using accuracy metrics

# Technologies Used
1. Python
2. Pandas
3. NumPy
4. Scikit-learn
5. Jupyter Notebook

# Dataset Used
## Dataset contains:
1. Fake news articles
2. Real news articles
## Dataset features:
1. title
2. text
3. subject
4. date

# Machine Learning Workflow
Data Collection
       ↓
Data Preprocessing
       ↓
Text Cleaning
       ↓
TF-IDF Vectorization
       ↓
Train-Test Split
       ↓
Logistic Regression Model
       ↓
Prediction
       ↓
Evaluation

# Text Preprocessing Techniques
1. Lowercase conversion
2. Removal of punctuation
3. Removal of URLs
4. Removal of HTML tags
5. Removal of numbers

# Algorithm Used
## Logistic Regression
Logistic Regression is used for binary classification:
Fake News - 0
Real News - 1
